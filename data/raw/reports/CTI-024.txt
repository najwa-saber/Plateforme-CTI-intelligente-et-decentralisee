LockMare encryptor technical analysis

The LockMare encryptor uses a hybrid scheme: each file is encrypted with a random symmetric key which is then protected with the operator's public key. It skips system folders to keep the machine bootable, deletes shadow copies and empties the recycle bin. The sample analysed (MD5 7ccb9f68bfa7dafa8368fcc001b21254, SHA-256 edf3e44a602937862e5fc72fde2b6a58db791e109df146fbb8b7f1715d1a51c5) contains a hardcoded payment page http://lockmare-pay.test/victim/portal. No decryption flaw was identified.
