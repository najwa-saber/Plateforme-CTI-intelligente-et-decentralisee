Exploitation of SMB vulnerability for lateral movement

An intrusion set exploited an unpatched remote code execution vulnerability in the file sharing service (CVE-2099-0901) to move laterally inside networks after initial access. The exploit tool (MD5 8708a4670bc5cf9d3689140a9ba24cfc) scans the internal subnet and compromises vulnerable servers. External command servers included patch-mgmt-sync.invalid. Network segmentation limited the spread in some environments.
