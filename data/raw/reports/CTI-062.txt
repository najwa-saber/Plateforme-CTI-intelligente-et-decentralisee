Remote code execution in OrbitCMS through deserialization

A deserialization flaw in OrbitCMS (CVE-2099-0311) allows unauthenticated remote code execution by sending a serialized object in a cookie. Proof-of-concept code was published and exploitation started within 24 hours. Exploited servers downloaded a script from http://orbit-cms-patch.example/fix.sh, which installed a backdoor. Scanning activity originated from 203.0.113.12 and 203.0.113.13.
